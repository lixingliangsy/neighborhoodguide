# NeighborhoodGuide — Feature pillars

## Core engine
- Writes lifestyle-focused neighborhood descriptions
- Matches highlights to the buyer or relocator profile
- Includes nearby highlights relevant to that profile

## Workflow & output
- Agents and relocation teams get location copy that sells lifestyle
- Ready for listings, packets, or site pages
- Buyer-matched rather than one generic blurb

## Trust & control
- Decision-support for marketing copy — not an appraisal or crime report
- No fabricated school-score or ranking claims
- Demo mode without a live API key
